# NairaBridge Digital Banking System
## MIT 8103 – Advanced Database Systems
### Final Database Portfolio Report

## 1. Overview

NairaBridge is a fictional Nigerian digital banking system that showcases various database concepts including database design, query optimization, transaction handling, NoSQL modeling and distributed databases.

Using sample banking data, this project looked at how modern banking systems handle their data.


## 2. Portfolio Summary

### Portfolio 1: Database Design and Modelling
Designed and created a relational database for the NairaBridge system using PostgreSQL. This included creating tables, relationships, constraints, sample data and queries. An Entity Relationship Diagram was also designed along with reconciliation queries.

### Portfolio 2: Query Processing and Optimisation
Used the `EXPLAIN ANALYZE` command to view the SQL query plans. Used sequential scans, indexes and database statistics to test out how they affect query performance.

### Portfolio 3: Transactions and Concurrency
Understood how to handle transactions and the ACID properties. Used COMMIT, ROLLBACK, isolation levels, row locks, deadlock and concurrency. Created and tested a controlled money transfer process.

### Portfolio 4: NoSQL and Advanced Data Models
Used MongoDB to implement document, key-value, and graph-style data models. Designed a Cassandra column-family schema for customer transaction history.

### Portfolio 5: Distributed and Cloud Database Exercise
Demonstrated the logical replication of PostgreSQL. Horizontal sharding and automatic shard routing was simulated. A service failure and recovery was demonstrated along with a database backup. Notes on distributed architectures, availability, consistency, disaster recovery, and CAP theorem were made.
